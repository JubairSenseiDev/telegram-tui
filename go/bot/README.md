# 🤖 Telegram TUI — Go bot

Standalone Telegram Bot API service for automation and lightweight replies.

## Run

```sh
export TELEGRAM_BOT_TOKEN="123:abc"   # get one from @BotFather
go run .
```

## Commands

`/start` · `/help` · `/ping` — plain messages are echoed back.

## Build

```sh
go build -o telegram-tui-bot .
```
